# ocs.church

The website for OCS: https://ocs.church

- `index.html`: the home page. The "God loves you this much" medallion, Romans 5:8, a **Learn more** button that finds the nearest LCMS churches by ZIP code using the [LCMS church locator](https://locator.lcms.org/church), Contact and About OCS ribbons, Luther's Rose and an LCMS link in the footer.
- `christianity.html`: "A Simple Explanation Of Christianity", Luther's Small Catechism (1529) in the public-domain 1921 English translation from the Concordia Triglotta. Linked from Luther's Rose.

Hosted free with GitHub Pages.
